# 60-second video

`Agentic-Board-60s.mp4` is a 1920×1080, 30 fps, 60-second captioned explainer built from the project's own artifacts: the playbook PDF, the interactive site, the Board Room app, and the FAQ. It includes an original music bed generated by `music.py` and has no voiceover; `narration.md` is a timed script for recording one.

Rebuild (needs Node with Playwright and Chromium, Python with NumPy, and ffmpeg):

```sh
python3 video/music.py /tmp/music.wav
node video/render.cjs video/Agentic-Board-60s.mp4 30 /tmp/music.wav
```

`scenes.html` holds the eight animated scenes; `render(t)` draws the frame at time `t`, and `render.cjs` screenshots each frame into ffmpeg. The images in `assets/` are screenshots of the site, the app, and PDF pages.
